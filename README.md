# COVID-19 X-ray Analyzer

An **AI-powered diagnostic web app** built with **PyTorch** and **Gradio** for analyzing **chest X-ray images** and detecting signs of **Pneumonia vs Normal lungs**.  


## 🚀 Features

- 🧠 **ResNet-50** deep learning model for binary classification.  
- 💻 Modern **Gradio UI** with a clean dark gradient theme.  
- ⚡ Runs on both **CPU and GPU** (auto-detects device).  
- 🧩 Works entirely **offline** — no external API calls.  
- 🛡️ Lightweight, responsive, and visually polished interface.
